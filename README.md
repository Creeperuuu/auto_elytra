# Auto Elytra — Minecraft 26.2

Client-side Fabric mod for automatic Elytra/chestplate swapping.

## Controls
- **R (default):** swap Elytra ↔ chestplate. Change it in **Options → Controls → Key Binds**.
- **Space while gliding:** immediately swap the Elytra for the best available chestplate, stopping flight midair.
- **Second jump while airborne:** equips an available Elytra.

Requires Fabric API and Java 25+.
